# 자료 화면

## 구조

```
assets/
  shared/          여러 편에서 재사용하는 도식 (빈틈 도식, 지질시대표 등)
  <EP>/shots.yaml  편별 배정표 — 어느 큐에 무엇을 깔지
  <EP>/*.png       그 편에서만 쓰는 자료
```

## 쓰는 법

1. `python3 tools/produce.py EP0XX` → `assets/EP0XX/shots.yaml` 뼈대 생성
   (이미 있으면 **덮어쓰지 않습니다.** 채워둔 경로가 날아가지 않습니다)
2. `file:` 에 이미지·영상 경로를 넣습니다 (리포 루트 기준)
3. `python3 tools/render.py EP0XX` → 해당 구간 배경으로 합성

```yaml
- cue: 9
  at: 17.8
  until: 20.8
  screen: '"무한 후퇴 요구" — A···C 사이에 B를 넣자 빈틈이 둘로 갈라지는 도식'
  file: assets/shared/gap-2.png
  fit: cover        # cover(가득 채우고 잘라냄) | contain(전체를 보이게)
```

**전부 채울 필요 없습니다.** 비워두면 그 구간은 단색 배경입니다.
자료가 깔린 구간에만 어둠막이 적용되고, 나머지는 브랜드 색 그대로입니다.

## 제작 규격

- **1080 × 1920** 권장. 다른 비율도 `fit` 으로 처리되지만 잘립니다
- **하단 42%는 자막 영역**입니다. 핵심 내용을 여기 두지 마세요 (어둠막이 덮습니다)
- 상단 12%도 피하세요 — 플랫폼 UI 안전영역
- 색은 브랜드 팔레트를 따르세요 → [02 브랜드](../docs/02-brand.md) §3

## ⚠ 저작권

**이미지에도 출처 기록 의무가 있습니다** → [09 리스크](../docs/09-risk-and-compliance.md) §1

- 논문 그림은 저작권이 있습니다. **데이터를 받아 직접 다시 그리는 것**이 가장 안전합니다
- 박물관 소장품 사진은 박물관이 권리를 주장하는 경우가 많습니다
- 직접 만든 도식(`assets/shared/*`)은 이 문제가 없습니다. 가능하면 이쪽으로

`content/sources.md` 에 이미지 출처도 함께 기록하세요.
분쟁 시 "어디서 가져왔는지 모른다"가 가장 나쁜 상태입니다.
