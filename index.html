1min_scientist uploader

An open-source command-line tool · GPL-3.0

A personal tool that uploads short-form science videos, produced by its operator, to that operator's own TikTok drafts.

It does not publish posts. Videos are sent to the account holder's TikTok inbox using the Content Posting API with the video.upload scope. The account holder then reviews, completes and publishes each post inside the TikTok app.

How it works

StepWhat happens
1. AuthenticateThe operator signs in through TikTok's own OAuth flow. The resulting token is stored only on the operator's computer.
2. CheckThe video is validated locally against TikTok's format requirements before anything is sent.
3. UploadThe file is transferred to the operator's own TikTok inbox as a draft.
4. PublishThe operator finishes and publishes the post themselves, in the TikTok app.

Scope of access

The tool requests one scope, video.upload. It cannot read the operator's videos, followers, analytics or messages, and it cannot publish anything on its own.

Privacy

There is no server, no database and no analytics. Nothing is collected from anyone other than the operator, and nothing is shared with any third party. See the Privacy Policy for detail.
