# 09. 리스크 · 준법

> 이 문서는 일반적인 실무 참고사항이며 **법률 자문이 아닙니다.**
> 실제 분쟁이 발생하거나 발생 우려가 있으면 변호사와 상담하세요.

## 1. 저작권

### 쓸 수 있는 것
- **직접 제작한 도표·애니메이션** (권장 — 가장 안전하고 브랜드에도 좋음)
- 퍼블릭 도메인 (미국 정부기관 저작물 다수: NASA, USGS, NOAA — 개별 확인 필요)
- CC 라이선스 이미지 — **저작자 표시 조건을 반드시 이행**
- 라이선스 구매한 음원·폰트

### 주의할 것
- **논문 그림의 전재**: 학술 논문 그림에도 저작권이 있습니다.
  상당수 저널이 교육 목적 이용에 관대하지만 **자동 허용은 아닙니다.**
  안전한 방법: **데이터를 받아 직접 다시 그리기.** 그리고 출처 표기.
- **상대 진영 영상 인용**: 비평 목적 인용은 일반적으로 인정되는 영역이지만,
  분량은 최소한으로, 반드시 비평·반박과 함께, 출처를 명시하세요.
  원본을 길게 붙여넣으면 인용이 아니라 복제가 됩니다.
- **화석·표본 사진**: 박물관 소장품 사진은 박물관이 권리를 주장하는 경우가 많습니다.

### 실무 규칙 — 도구가 강제합니다

```bash
python3 tools/fetchmedia.py search "Tiktaalik"   # 자유 라이선스만 자동 승인
python3 tools/fetchmedia.py credits               # 표시 의무가 있는 자료 목록
```

1. `fetchmedia.py` 로 받으면 `assets/CREDITS.yaml` 에 저작자·라이선스·원본 URL이 **자동 기록**됩니다
2. `produce.py` 가 CC BY 계열 자료의 **저작자 표시를 고정 댓글에 자동 삽입**합니다
3. `claimctl.py validate` 가 **출처 기록 없는 외부 자료를 발행 차단**합니다

직접 넣은 파일은 `assets/CREDITS.yaml` 에 수동으로 추가해야 검수를 통과합니다.
`assets/shared/` 의 자체 제작 도식은 예외입니다.

> 분쟁 시 **"어디서 가져왔는지 모른다"가 가장 나쁜 상태**입니다.
> 그래서 사람의 기억이 아니라 도구가 막습니다.

## 2. 명예훼손

한국법에서는 **사실 적시도 명예훼손이 될 수 있습니다** (형법 제307조 제1항).
이 채널은 실명 인용을 하므로 실제로 관련 있는 리스크입니다.

**방어선:**
1. **공개된 발언·출판물만** 인용. 사적 대화·비공개 자료 금지
2. **주장에 대한 평가**로 한정: "이 주장은 데이터와 맞지 않습니다" (O) /
   "이 사람은 사기꾼입니다" (X)
3. **동기 추정 금지**: "돈 때문에" "알면서도 속인다" 같은 서술은 쓰지 않습니다.
   틀렸다는 것과 속인다는 것은 완전히 다른 주장이고, 후자는 입증 책임이 우리에게 옵니다
4. 인용은 **맥락 포함**. 잘라내기 인용은 왜곡 주장을 부릅니다
5. **공공의 이익**에 관한 것이라는 점이 드러나게 — 과학 교육 목적임을 명확히

> 레드라인과 동일합니다 → [편집 정책](03-editorial-policy.md) §1.
> **편집 정책을 지키면 이 리스크의 대부분이 자동으로 관리됩니다.**

## 3. 플랫폼 정지

종교 인접 주제라 신고가 누적될 수 있습니다.

**예방:**
- 매 편 고정 댓글에 "이 채널은 종교를 비판하지 않습니다" 명시
- 종교 상징의 조롱적 사용 금지
- 썸네일에 자극적 이미지 사용 금지

**대비:**
- **모든 영상 원본을 로컬 + 클라우드 이중 백업.** 채널이 정지되면 플랫폼에서 못 받습니다
- 대본과 출처가 이 리포에 버전 관리됨 → **이의제기 시 "근거 있는 교육 콘텐츠"임을 입증하는 자료**
- 두 플랫폼 운영 자체가 리스크 분산입니다. 한쪽이 정지돼도 나머지가 남습니다
- 구독자에게 **외부 연락 수단**(뉴스레터 등)을 일찍 확보해두세요

**이의제기 시:** 감정적 호소 대신 **출처 목록과 대본**을 제출하세요.

## 3-1. 검토 후 수용한 리스크

운영자가 위험을 인지하고 진행하기로 결정한 항목입니다.
문제 발생 시 대응 근거로 남깁니다.

| 항목 | 지적된 위험 | 결정 |
|---|---|---|
| 프로필 이미지 (종교 도상) | 플랫폼 종교 정책, 1차 타깃 이탈, 정보통신망법 §70① '비방할 목적' 정황 | **운영자 판단으로 유지** (2026-09-20) |

신고·제재가 실제로 발생하면 [§3 플랫폼 정지](#3-플랫폼-정지) 절차로 대응하고,
이의제기 시 대본·출처 기록을 제출하세요.

## 4. 개인 안전

- 실명·거주지·직장이 드러나는 정보 노출 금지 (배경 화면, 창밖 풍경 포함)
- 협박·신상털기 발생 시: **캡처 → 플랫폼 신고 → 필요 시 수사기관**. 직접 대응 금지
- 오프라인 행사 참여 시 사전에 위험 평가

## 5. 사실 오류 대응 (가장 높은 확률의 리스크)

법적 리스크보다 **우리가 틀리는 것**이 훨씬 자주 일어납니다.

절차는 [편집 정책](03-editorial-policy.md) §5에 있습니다. 요지:
**24시간 내 고정 댓글 정정 → 7일 내 정정 편 → 리포에 기록.**

영상을 조용히 내리지 마세요. 삭제는 은폐로 읽히고,
이 채널의 유일한 자산인 신뢰를 직접 깎습니다.

## 6. 발행 전 최종 확인

```
☐ 모든 사실 주장에 출처가 있다
☐ 인용은 원문 맥락을 확인했다
☐ 사람이 아니라 주장을 비판했다
☐ 동기를 추정하지 않았다
☐ "그러므로 신은 없다"로 넘어가지 않았다
☐ 이미지·음원 라이선스를 확인하고 기록했다
☐ 아무 프레임을 캡처해도 오해 소지가 없다
☐ 영상 원본을 이중 백업했다
```
