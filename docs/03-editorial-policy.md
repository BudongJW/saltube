# 03. 편집 정책 · 사실검증 · 정정

> 이 문서는 협상 대상이 아닙니다. 조회수를 이유로 완화되지 않습니다.
>
> **대본의 구조**는 [14 논박 방법](14-debunking-method.md)을 따릅니다 —
> 이 문서가 '무엇을 말하면 안 되는가'라면, 그쪽은 '어떤 순서로 말해야 먹히는가'입니다.

## 1. 레드라인 (위반 시 발행 취소)

절대 하지 않는 것:

1. **종교·신자 비하 금지.** "기독교인은 무지하다" 류 문장은 즉시 반려.
   비판 대상은 언제나 **문장 단위의 경험적 주장**입니다.
2. **싸잡기 금지.** 창조과학 ≠ 기독교. 가톨릭교회는 진화를 수용하고(1996년 요한 바오로 2세
   교황청 과학원 담화), 다수 주류 개신교단도 마찬가지입니다.
   **이 사실을 주기적으로 명시하세요** — 신자 시청자를 적이 아니라 관객으로 만듭니다.
3. **인용 왜곡 금지.** 창조과학의 대표적 기법인 quote mining을 우리가 하면 채널은 끝납니다.
   인용은 반드시 앞뒤 문맥 확인. 원문 링크를 `content/sources.md`에 기재.
4. **무신론 전도 금지.** "그러므로 신은 없다"는 이 채널의 결론이 아닙니다.
   우리의 결론은 항상 **"이 특정 주장은 증거와 맞지 않는다"**까지입니다.
   과학은 초자연적 존재에 대해 판정하지 않습니다. 이 선을 넘는 순간 우리도 과학을 참칭하게 됩니다.
5. **개인 신상·사적 정보 금지.** 공개 강연·출판물·공식 홈페이지의 발언만 인용 대상.
   거꾸로 말하면 **공개된 발언은 실명으로 비판합니다.** 직함은 방패가 아닙니다 —
   목사가 공개 설교에서 과학적 주장을 했다면 그 주장은 검증 대상입니다.
   → 실행 사양: [11 대결 포맷](11-format-confrontation.md)
6. **출처 없는 수치 금지.** "알려져 있다", "연구에 따르면" 만으로는 통과 못 합니다.
7. **상대 대사 창작 금지.** 실존 인물·단체의 발언으로 제시되는 모든 문장은
   **원문 그대로**여야 합니다. 요약이 필요하면 인용부호를 쓰지 말고 화면에 `요약` 표시.
   지어낸 대사를 실명에 붙이는 것은 정보통신망법 §70②(허위사실 적시) 영역이고,
   동시에 상대에게 "우리가 언제 그렇게 말했나"라는 완벽한 방어권을 넘겨줍니다.
   드라마·AI 캐릭터 포맷에도 그대로 적용됩니다. → [11 대결 포맷](11-format-confrontation.md) §1
8. **결말 생략 금지.** 사건을 다룰 때 **결과를 빼면 허위가 됩니다.**
   2012년 교과서 사건은 "삭제가 추진됐다"까지가 아니라 "9월에 한림원 패널이
   기각했고 시조새는 남았다"까지가 사실입니다. 앞부분만 쓰면 제목도 내용도
   실제로 일어나지 않은 일을 주장하게 됩니다. 실명 단체가 걸려 있으면
   정보통신망법 §70②(허위사실 적시) 영역입니다.
   **분노는 사실 안에서 만듭니다** — 이 편의 분노 포인트는 "교과서가 바뀌었다"가
   아니라 "교육부가 심사도 없이 넘겼다"이고, 후자는 실제로 일어난 일입니다.
9. **국가·민족 비하 금지 (싸잡기 금지의 국가 버전).**
   해외 시청자용 번역판에서 특히 위험합니다. 2012년 사건의 주어는 "한국"이 아니라
   **특정 단체와 그것을 검토 없이 전달한 부처**입니다.
   **시청자층의 반감 정서에 올라타는 편집은 하지 않습니다.** 조회수는 나오지만
   그 순간 채널은 "증거를 따진다"에서 "미워할 대상을 판다"로 바뀌고,
   우리가 창조과학을 비판할 때 쓰는 근거를 스스로 버리게 됩니다.
   교과서 창조론 논쟁은 미국(도버 2005)·터키·브라질에도 있었습니다 —
   한국만의 일이 아니라는 점을 고정 댓글에 명시하세요.

## 2. 사실검증 3단계

모든 대본은 발행 전 3단계를 통과해야 합니다. `tools/claimctl.py validate`가 1·2단계를 기계 검사합니다.

### 1단계 — 출처 추적 (기계 검사 가능)
- 대본의 모든 사실 주장에 `[S1]`, `[S2]` 형식의 출처 마커가 붙어 있는가
- front matter의 `sources:` 항목이 각 마커에 대응하는가
- 각 출처에 **DOI / arXiv ID / ISBN / 기관 URL** 중 하나가 있는가
- **블로그·위키백과·유튜브 영상은 출처로 불가** (배경 조사용으로만)

### 2단계 — 원문 대조 (사람 + 기계 1차 거름망)

```bash
python3 tools/attest.py init EP0XX   # 근거 항목 뼈대 생성
python3 tools/attest.py check        # 인용이 실제 출처에 존재하는지 대조
```

대본의 모든 `[S-XXX]` 마커에 **그 출처가 무엇을 뒷받침하는지**와
**원문 그대로의 인용문**을 남겨야 합니다. 초록을 받을 수 있는 출처는
기계가 인용문의 실재 여부를 대조하고, 그렇지 않으면 **사람이 서명**해야 합니다.

> **기계는 한국어 대본과 영어 초록의 의미 일치를 판정하지 못합니다.**
> 그러니 판정하지 않습니다. 대신 지어낸 인용을 잡고, 사람이 원문을 봤다는
> 증거를 남기게 합니다. **아래 사람 확인 항목은 여전히 필수입니다.**

- 인용문을 원문에서 직접 확인했는가? (2차 인용 금지)
- 숫자의 **단위·오차범위**를 그대로 옮겼는가?
  예: 지구 나이는 "45억 년"이 아니라 **45.4 ± 0.5억 년** [Patterson 1956 계열 측정]
- 논문의 결론이 우리가 쓰는 방향과 실제로 일치하는가? (초록만 읽고 쓰지 말 것)
- **그 수치가 그 논문의 것인가?** 후속 논문의 수치를 앞선 논문에 붙이지 않았는가

> **실제 사례**: EP004가 빙하코어 "80만 년"을 EPICA 2004 논문으로 인용하고 있었는데,
> 그 논문이 보고한 값은 **74만 년**이었습니다. 80만 년은 2007년 확장 기록의 값입니다.
> 실재하는 논문이었고 DOI도 맞았지만 **그 논문은 우리가 말한 것을 말하지 않았습니다.**
> `attest` 도입 과정에서 발견되어 `S-JOUZEL-2007`로 교체했습니다.

### 3단계 — 반대 심문 (사람, 필수)
대본을 **창조론자 입장에서** 읽고 다음을 답해봅니다:
- 이 반박에 대한 표준 재반박이 무엇인가? 그걸 대본이 이미 막고 있는가?
- 내가 과장하거나 가장 강한 형태의 상대 주장을 피해가지 않았는가? (**허수아비 금지**)
- 이 영상 캡처 한 장이 맥락 없이 돌아다니면 오해를 살 부분이 있는가?

> **원칙: 상대 주장의 가장 강한 버전을 반박한다.** 약한 버전을 때리면 댓글에서
> "그건 우리 주장이 아니다"로 역공당하고, 그 클립만 잘려 유통됩니다.

## 3. 확실성 등급 (대본 front matter `confidence`)

| 등급 | 의미 | 화면 표현 |
|---|---|---|
| `settled` | 과학계 수렴 결론 | "입니다" — 단정 |
| `strong` | 증거 매우 우세, 세부 논쟁 존재 | "증거는 압도적으로 ~를 가리킵니다" |
| `active` | 활발한 연구 영역 | "현재로서는", "가설 단계입니다" |

**`active`를 `settled`처럼 말하는 것이 이 채널이 망하는 가장 빠른 길입니다.**
생명의 기원 관련 내용은 대부분 `active`입니다. 진화의 사실성은 `settled`입니다. 섞지 마세요.

## 4. 흔한 자책골 (우리가 자주 틀리는 것들)

반박하다가 **우리가** 부정확해지는 지점들. 대본 검수 시 특히 확인:

| 자주 하는 실수 | 정확한 서술 |
|---|---|
| "진화론은 생명의 기원을 설명한다" | 진화는 **이미 존재하는** 생명의 변화를 다룸. 생명 기원은 별개 분야(abiogenesis) |
| "인간은 원숭이에서 진화했다" | 인간과 현생 유인원은 **공통조상**에서 갈라짐 |
| "진화는 진보다 / 더 우월해진다" | 진화는 방향성 없음. 환경 적합도에 대한 상대적 변화일 뿐 |
| "빅뱅이 진화의 시작" | 우주론과 생물 진화는 별개 이론 |
| "적자생존" (herbert spencer 용어) | **자연선택**이 정확한 용어. "적자생존"은 동어반복 비판을 자초 |
| "과학은 증명했다" | 과학은 **입증**이 아니라 **반증 실패의 누적**. "증명"은 수학 용어 |
| 흔적기관 = 기능 없는 기관 | vestigial = **원래 기능을 상실/축소**한 기관. 다른 기능은 있을 수 있음 (맹장의 면역 기능 등) |
| 실러캔스 = "살아있는 화석, 진화 안 함" | 현생 실러캔스는 화석종과 **다른 속(屬)**. 계통 지속 ≠ 정체 |

## 5. 정정 절차

틀렸다는 게 확인되면:

1. **24시간 내** — 해당 영상 고정 댓글에 정정 내용 게시 (영상 삭제하지 않음)
2. **7일 내** — 정정 편 발행. 포맷은 [02 브랜드](02-brand.md) §5 참조
3. **영구** — `content/scripts/` 해당 대본 front matter에 `corrections:` 블록 추가하고 커밋

**영상을 조용히 내리지 않습니다.** 삭제는 은폐로 읽히고, 이 채널의 유일한 자산인
신뢰를 직접 깎습니다. 정정 편은 손실이 아니라 **차별화 포인트입니다** —
창조과학 측이 하지 못하는 일을 우리가 공개적으로 하는 장면이기 때문입니다.

## 6. 반론 처리 기준

댓글·다른 채널의 반박에 대해:

| 상황 | 대응 |
|---|---|
| 우리가 사실관계를 틀림 | §5 정정 절차. 감사 표시. |
| 상대가 사실관계를 틀림 | 1회 출처와 함께 답변. 반복 시 무응답. |
| 해석 차이 / 철학적 논쟁 | 답변하되 "이건 과학이 판정할 영역이 아닙니다" 명시 |
| 인신공격·욕설 | 무응답, 필요 시 숨김. 논쟁 상대로 승격시키지 않음 |
| 같은 주장 반복 다수 | 개별 답변 대신 **에피소드로 제작** (E 기둥) |

마지막 항목이 중요합니다. 반복되는 반론은 **콘텐츠 소재**입니다.
댓글창에서 소모하지 말고 백로그(`content/claims.yaml`)에 추가하세요.
