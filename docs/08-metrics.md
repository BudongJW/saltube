# 08. 지표

## 1. 1차 지표: 완주율 (평균 조회율)

**다른 모든 지표보다 이게 먼저입니다.**

| 구간 | 판정 | 행동 |
|---|---|---|
| 70%+ | 매우 좋음 | 길이를 조금 늘려 정보량 확대 시도 가능 |
| 60~70% | 목표 구간 | 유지 |
| 50~60% | 주의 | 훅(첫 3초)과 중반 늘어짐 점검 |
| 50% 미만 | 문제 | **발행량 늘리지 말고 포맷부터 고칠 것** |

완주율이 낮은 상태에서 발행을 늘리면 채널 전체 평가가 눌립니다.
**품질 문제를 물량으로 덮을 수 없습니다.**

### 이탈 지점 분석
플랫폼 분석에서 이탈 곡선을 보세요. 우리 콘텐츠의 전형적 이탈 지점:
- **0~3초**: 훅 실패. 주장 인용이 지루하거나 화면이 밋밋함
- **10~15초**: 배경 설명이 길다. 증거로 빨리 넘어갈 것
- **35~45초**: 결론이 늦다. 결론을 앞당기고 근거를 뒤에 붙이는 구조 시도

## 2. 2차 지표

| 지표 | 의미 | 목표(90일) |
|---|---|---|
| 저장/공유 | **가장 값진 신호.** "나중에 쓰겠다" = 자료 가치 인정 | 조회수의 1.5%+ |
| 댓글 중 **질문** 비율 | 교육 효과의 대리 지표 | 전체 댓글의 20%+ |
| 구독 전환 | 채널 자체에 대한 신뢰 | 조회수의 0.5%+ |
| 재방문 시청자 비율 | 일회성 바이럴 vs 실제 팬 | 30%+ |

**좋아요 수는 추적하지 마세요.** 이 주제에서 좋아요는 동의 표시일 뿐,
콘텐츠 품질과 상관이 약하고 진영 확인용 신호에 가깝습니다.

## 3. 90일 목표

| 항목 | 목표 | 최소선 |
|---|---|---|
| 발행 편수 | 36편 | 24편 |
| 평균 완주율 | 60% | 50% |
| 유튜브 구독 | 3,000 | 1,000 |
| 틱톡 팔로워 | 5,000 | 1,500 |
| 정정 편 | 1편+ | — |
| 교사·강사 인용 확인 | 1건 | — |

마지막 두 항목은 숫자가 작지만 **채널 성격을 규정하는 지표**입니다.
정정 편이 0편이라면 둘 중 하나입니다 — 실수가 없었거나, 실수를 못 찾고 있거나.
90일간 36편을 내면서 오류가 하나도 없을 가능성은 낮습니다. **못 찾고 있을 확률이 높습니다.**

## 4. 추적하지 않는 것

- **논쟁 유발도** — 댓글 싸움은 단기 노출을 올리지만 채널을 갈등 콘텐츠로 분류시킵니다
- **구독자 수 단독** — 완주율 없는 구독자는 유령입니다
- **경쟁 채널 대비 순위** — 통제 불가능하고 판단을 왜곡합니다

## 5. 월간 리뷰 (30분, 매월 1회)

1. 상위 3편 / 하위 3편의 **첫 3초**를 나란히 재생
2. 이탈 곡선에서 공통 이탈 지점 확인
3. 댓글에서 반복된 반론 → `content/claims.yaml`에 추가
4. 기둥 비중 확인: `python3 tools/claimctl.py backlog`
5. **사실 오류 지적이 있었는데 처리 안 한 게 있는지 확인** ← 가장 중요

## 6. 피봇 트리거

아래 중 하나라도 해당하면 계획을 바꿉니다:

| 신호 | 해석 | 대응 |
|---|---|---|
| 8주차 완주율 50% 미만 | 포맷 실패 | 길이 40초로 단축, 구조 재설계 |
| 정정 사안 2회 이상 발생 | **조사 공정 결함** | 발행 중단하고 게이트 2 강화 |
| 댓글의 70%+가 진영 싸움 | 톤 실패 | 톤 재점검, C·B 기둥 비중 확대 |
| 12주간 주 3회 유지 실패 | 리소스 과대 산정 | 주 2회로 공식 하향 (죄책감 없이) |

두 번째 줄을 특히 지키세요. **틀린 내용을 빠르게 많이 내는 것이
이 채널이 할 수 있는 최악의 실패입니다.** 그 순간 우리는 비판하던 대상과 같아집니다.
