# 07. 런칭 90일 계획

> 전제: 1인 운영, 주당 가용 20~25시간. 이보다 적으면 **주 2회로 낮추세요.**
> → [파이프라인](05-production-pipeline.md) 소요시간표 참조

## Phase 0 — 준비 (D-14 ~ D-1, 2주)

**목표: 발행 시작 전에 6편을 미리 쌓아둔다.** 이게 이 계획의 핵심입니다.
재고 없이 시작하면 3주차에 반드시 펑크 나고, 한 번 끊기면 복귀가 어렵습니다.

| | 할 일 |
|---|---|
| D-14 | 채널명 최종 확정 → [전략](01-strategy.md) §4. 3개 플랫폼 핸들 동시 확보 |
| D-13 | 로고·썸네일 템플릿·자막 프리셋 제작 → [브랜드](02-brand.md) |
| D-12~8 | **EP001~EP004 조사·대본** (이미 초안 있음 — 게이트 2·3 수행) |
| D-7~4 | EP005~EP006 신규 작성 (C005 지구나이, C011 유익돌연변이 — 난이도 2) |
| D-3~2 | 6편 전부 녹음·편집 |
| D-1 | 계정 세팅: 프로필, 배너, 금지어 필터 → [커뮤니티](06-community-moderation.md) §3 |

**Phase 0 종료 조건**: `claimctl.py validate` 통과한 대본 6편 + 완성 영상 6편.
**이게 안 되면 런칭을 미루세요.** 재고 없는 런칭은 실패 확률이 훨씬 높습니다.

## Phase 1 — 발행 시작 (1~4주차, 12편)

목표: **리듬 확립**. 성장이 아니라 습관입니다.

- 주 3회(월·수·금) 발행. 재고를 매주 2편씩 보충해 **버퍼 4편 유지**
- 난이도 1~2만 발행. 어려운 편은 아직
- 기둥 배분: A 6편, B 2편, C 2편, D 2편 — A만 하지 마세요
- **4주차 말 점검**: 완주율이 50% 미만이면 대본이 긴 것입니다. 길이부터 줄이세요

이 구간의 조회수는 대부분 낮습니다. **정상입니다.** 여기서 포기하는 게 가장 흔한 실패입니다.

## Phase 2 — 최적화 (5~8주차, 12편)

목표: **무엇이 먹히는지 알아낸다.**

- 상위 3편과 하위 3편의 **첫 3초**를 나란히 비교. 훅 패턴을 찾으세요
- A/B: 같은 주제를 질문형 제목 vs 단정형 제목으로 (다른 회차에)
- 난이도 3 편 투입 시작 (C004 연대측정, C008 대홍수, C009 염색체)
- **첫 정정 편을 이 구간에 넣으세요.** 실수가 없었다면 "자주 오해받는 지점" 편으로 대체
- 6주차: 댓글에서 반복된 반론 top 3를 `claims.yaml`에 추가

## Phase 3 — 확장 (9~12주차, 12편)

목표: **자산화.**

- 2부작 시리즈 첫 시도 (예: C008 대홍수 지질학 — 증거가 많아 1편에 안 들어감)
- 국내 창조과학 자료 직접 인용 편 제작 → **이게 이 채널의 진짜 해자입니다** → [전략](01-strategy.md) §2
- 유튜브 **재생목록**을 기둥별로 구성 (검색 유입 대비)
- 교사·강사 대상 "수업용 자료" 형태의 정리 게시물 1회

## 12주차 판정

[08 지표](08-metrics.md)의 기준으로 판정합니다. 세 가지 중 하나:

| 판정 | 조건 | 행동 |
|---|---|---|
| **계속** | 완주율 60%+ , 구독 3,000+ | Phase 4 설계 |
| **조정** | 완주율 60%+ , 구독 미달 | 콘텐츠는 맞음, **유통이 문제**. 제목·훅 집중 개선 |
| **재설계** | 완주율 50% 미만 | **대본 포맷 문제.** 길이·구조를 근본적으로 재검토 |

완주율이 낮은데 발행량만 늘리는 건 손해를 키우는 겁니다.
**완주율이 모든 판단의 1차 지표입니다.**

## 번아웃 방지 (계획의 일부)

- **재고 4편 밑으로 내려가면 그 주 발행을 2회로 줄이세요.** 재고 소진이 중단의 직행로입니다
- 월 1회는 발행 없는 주말을 두세요
- 댓글 확인 시간 고정 → [커뮤니티](06-community-moderation.md) §7
