# 06. 커뮤니티 대응

이 주제는 댓글이 거칠어집니다. **미리 정해두지 않으면 반드시 즉흥적으로 대응하게 되고,
즉흥 대응은 거의 항상 채널에 손해입니다.**

## 1. 대전제

> **댓글에서 싸우는 사람은 설득되지 않습니다. 설득되는 사람은 댓글을 쓰지 않고 읽습니다.**

모든 답글은 **논쟁 상대가 아니라 지켜보는 100명**을 향해 씁니다.
이 관점을 잃는 순간 답글이 길어지고, 감정적이 되고, 캡처당합니다.

## 2. 분류와 대응

| 유형 | 판별 | 대응 |
|---|---|---|
| **진짜 질문** | 물음표가 있고 공격적 표현이 없음 | **최우선 답변.** 출처와 함께 친절하게 |
| **정당한 지적** | 우리 사실관계 오류를 정확히 짚음 | **감사 + 정정.** 24시간 내 고정 댓글, 7일 내 정정 편 |
| **정형 반론** | claims.yaml에 이미 있는 주장 | 1회 짧게 답하고 "다음 편에서 다룹니다" |
| **반복 논쟁** | 같은 사람이 3회 이상 | **무응답.** 이미 답한 링크만 1회 |
| **인신공격·욕설** | — | **무응답 + 숨김.** 차단은 최후 수단 |
| **종교 비하 (우리 편)** | 우리 시청자가 신자를 조롱 | **숨김 + 필요 시 고정 댓글로 선긋기** |

마지막 항목을 절대 빠뜨리지 마세요. **우리 편의 조롱을 방치하면 댓글창이
"과학 팬 vs 신자" 전장이 되고, 그 순간 이 채널은 교육 채널이 아니라 진영 채널이 됩니다.**
비타깃 시청자는 댓글창을 보고 채널의 성격을 판단합니다.

## 3. 자동 필터 (채널 설정)

두 플랫폼 모두 금지어 필터를 제공합니다. 등록할 것:

- 종교·교단 비하 표현 (**우리 편이 쓰는 것 포함**)
- 특정 인물 실명 + 욕설 조합
- 지역·출신 비하

**주의**: 반론 자체를 필터링하지 마세요. 비판 댓글을 지우는 채널로 알려지면
우리가 비판하는 태도와 구별되지 않습니다. 필터는 **욕설**에만 걸고, **반론은 남겨둡니다.**

## 4. 고정 댓글 (매 편 필수)

```
출처
[S-XXX] 저자, 제목, 저널 권(연도) 쪽. doi:...

이 채널은 종교를 비판하지 않습니다. 검증 가능한 주장만 다룹니다.
```

두 번째 줄은 장식이 아닙니다. **신고 대응 시의 방어선이자,
신자 시청자에게 "당신을 공격하는 게 아니다"라는 신호**입니다.

## 5. 브리게이딩 (조직적 유입) 대응

특정 커뮤니티에서 조직적으로 몰려오는 경우:

1. **당황해서 영상 내리지 마세요.** 노출 급증이므로 오히려 기회일 수 있습니다
2. 댓글을 일시적으로 **승인제**로 전환 (사후 해제)
3. 개별 대응 금지. 대신 **고정 댓글 1개**로 핵심 반론 3가지에 한 번에 답변
4. 반복 주장은 기록해 **다음 에피소드 소재**로 (E 기둥)
5. 협박·신상 위협이 있으면 캡처 후 플랫폼 신고 + 필요 시 수사기관

## 6. 다른 채널의 반박 영상

- **사실관계 반박** → 우리가 틀렸으면 정정 편. 맞았으면 1회만 응답하고 종료
- **영상 대 영상 공방** → **하지 마세요.** 시리즈가 되면 양쪽 다 진영 채널이 됩니다
- 인용·언급 시 **상대 영상의 주장을 정확히** 옮길 것. 우리가 quote mining을 하면 끝입니다

## 7. 운영자 자기 관리

이건 부록이 아니라 운영 항목입니다.

- **댓글 확인 시간을 정해두세요** (예: 하루 2회, 30분). 상시 확인은 소진됩니다
- 감정이 올라온 상태로 답글을 쓰지 마세요. 초안을 쓰고 **1시간 뒤에 보내세요**
- 채널을 그만두게 만드는 건 대개 조회수가 아니라 댓글창입니다. 이 문서가 존재하는 이유입니다
