# 02. 브랜드 가이드

## 1. 톤앤매너

**한 문장: 차분한 확신. 논쟁 중인 사람이 아니라, 이미 답을 아는 사람의 말투.**

흥분하면 집니다. 창조론 반박 콘텐츠가 실패하는 가장 흔한 이유는 화자가 화가 나 보여서
시청자가 "저 사람도 똑같이 믿는 사람이네"라고 판단하기 때문입니다.

| 쓴다 | 안 쓴다 |
|---|---|
| "이 주장이 맞으려면 A가 참이어야 합니다. 그런데 측정값은 B입니다." | "말도 안 되는 소리죠" |
| "1996년 논문을 보겠습니다." | "과학자들은 다 알고 있어요" (익명 권위) |
| "이 부분은 아직 논쟁 중입니다." | 모르는 걸 아는 척 |
| "틀렸습니다." (주장에 대해) | "멍청하다" (사람에 대해) |
| "그 인용은 원문과 다릅니다. 원문은 이렇습니다." | "거짓말쟁이" |

### 단정해도 되는 것 / 유보해야 하는 것

- **단정**: 지구 나이 45.4억 년, 공통조상, 방사성 붕괴 상수, 진화의 사실성
  → 이건 "논쟁 중인 학설"이 아니라 수렴된 결론입니다. 양비론으로 다루면 오히려 부정확합니다.
- **유보**: 생명의 기원(abiogenesis)의 구체적 경로, 캄브리아 폭발의 정확한 촉발 요인,
  일부 계통수 세부 가지 → **"아직 모른다"고 말하는 것이 채널의 무기입니다.**
  창조과학은 모른다고 말하지 못합니다. 우리는 말할 수 있습니다. 이 대비가 설득력입니다.

> **"모르는 것을 모른다고 말할 수 있다"가 우리와 저쪽의 가장 큰 차이입니다.
> 절대 이 카드를 버리지 마세요.**

## 2. 화자 페르소나

- **이름**: 미정 (실명 또는 일관된 활동명)
- **위치**: 교사에 가깝고, 검사(prosecutor)에 가깝지 않음
- **1인칭**: "제가" / 시청자 호칭: "여러분" 또는 호칭 생략
- **얼굴 노출**: 선택. 미노출 시 손+자료 화면 중심(TikTok에서 검증됨).
  다만 **목소리 일관성은 필수** — 회차마다 TTS 보이스가 바뀌면 신뢰도가 무너집니다.

## 3. 비주얼

### 컬러
```
--ink        #12151A   본문 텍스트 / 배경(다크)
--paper      #F5F3EE   배경(라이트) — 종이 질감
--evidence   #2E7D6B   증거·사실 강조 (청록)
--claim      #B4472F   창조론 주장 인용 (벽돌색)
--accent     #E0A800   수치·연도 하이라이트
```
**규칙: 창조론 주장 인용은 항상 `--claim`, 검증된 사실은 항상 `--evidence`.**
색만 봐도 지금 화면의 문장이 "저쪽 주장"인지 "확인된 사실"인지 구분되게 합니다.
음소거로 보는 시청자(쇼츠의 30~40%)에게 이게 핵심 장치입니다.

### 타이포
- 제목/자막: **Pretendard Bold** (오픈소스, 상업 이용 가능, 한글 가독성 최상)
- 숫자/데이터: **JetBrains Mono** 또는 Pretendard Tabular — 숫자가 흔들리지 않게
- 자막 최소 크기: 1080×1920 기준 **56px 이상**, 외곽선 또는 반투명 박스 필수
- 안전영역: 상단 12%, 하단 20% 비움 (UI 겹침 방지) → [04 플랫폼](04-platform-playbook.md)

### 화면 문법
1. **0~2초**: 주장 텍스트가 `--claim` 색으로 전체 화면
2. **2~8초**: 화자 또는 자료
3. **8~45초**: 증거 — 그래프/사진/화석 이미지, 출처는 **항상 화면 하단 고정**
4. **마지막 5초**: 결론 한 문장 + 출처 요약

### 출처 표기 (화면)
우하단 고정, 11~13px, 형식: `Nature 2006, doi:10.1038/nature04639`
**출처 자막 없는 컷은 편집 단계에서 반려.** → [05 파이프라인](05-production-pipeline.md)

## 4. 사운드

- BGM: 저음 위주 무드, **음악이 말보다 커지면 안 됨** (-18dB 이하)
- 효과음: 최소. "띠용" 류 밈 효과음 금지 — 조롱 톤으로 읽힘
- 음성: -14 LUFS 정규화(**2패스**), 말 속도 **분당 약 302음절** (실측, rate +30%)
  → 330~380은 추정치였고 29% 낙관적이어서 **5편 전부 60초를 넘겼습니다.**
  실측: rate +15% 에서 275, +30% 에서 302.
  속도나 엔진을 바꾸면 다시 재고 `claimctl.py`의 `SYLLABLES_PER_MIN`을 갱신하세요.
  → 재는 법과 2패스 정규화: [05 제작 파이프라인](05-production-pipeline.md) ⑦·⑧.6
- **TTS 음성은 `tools/tts.py` 상단 상수로 고정**합니다. 회차마다 바꾸지 마세요.
  생성된 mp3는 보관하세요 — 서비스 쪽 음성이 바뀌어도 기존 편은 영향받지 않습니다.
- 라이선스: 저작권 프리만 사용, `content/sources.md`에 음원 출처도 기록

## 5. 반복 요소 (채널 기억 장치)

- **오프닝 고정 문구**: "이 주장, 증거 있나요?" (1.5초, 매 편 동일)
- **증거 전환음**: 증거 제시 직전 동일한 짧은 사운드 → 조건반사 형성
- **아웃트로**: "출처는 고정 댓글에." (2초) — 실제로 매 편 고정 댓글에 출처 전문 게시
- **정정 편 전용 포맷**: 배경색 반전 + "정정" 워터마크. 숨기지 않고 오히려 눈에 띄게.
