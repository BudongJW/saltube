# 04. 플랫폼 운영

> ⚠️ **플랫폼 사양과 정책은 자주 바뀝니다.** 아래 수치는 작성 시점 기준이며,
> 런칭 직전 공식 헬프센터에서 반드시 재확인하세요. 특히 길이 한도와 수익화 조건.

## 1. 길이 정책 — 왜 60초인가

유튜브 쇼츠는 2024년 10월부터 **최대 3분**을 지원하고, 틱톡은 그보다 더 깁니다.
그럼에도 이 채널은 **60초 이내**를 기준으로 삼습니다. 이유는 규격이 아니라 **완주율**입니다.

- 완주율은 두 플랫폼 모두에서 가장 강한 추천 신호입니다.
- 90초짜리를 50% 보는 것보다 55초짜리를 90% 보는 쪽이 유리합니다.
- 우리 콘텐츠는 정보 밀도가 높아 체감 길이가 실제보다 깁니다.

`tools/claimctl.py validate`가 70초 초과를 **오류**로 막습니다. 이건 플랫폼 한도가 아니라
우리가 정한 편집 기준입니다. 넘기고 싶으면 **2부작으로 쪼개세요** — 시리즈물은 추천에 유리합니다.

## 2. 규격 (공통)

| 항목 | 값 |
|---|---|
| 해상도 | 1080 × 1920 (9:16) |
| 프레임 | 30fps (자료 화면 많음 — 60fps 불필요) |
| 코덱 | H.264 / AAC |
| 음량 | -14 LUFS, 트루피크 -1dBTP |
| 안전영역 | 상단 12%, 하단 20% (UI·캡션 겹침 방지) |
| 자막 | **번인 필수** (플랫폼 자동자막에 의존 금지 — 과학 용어 오인식 심함) |

번인 자막은 선택이 아닙니다. 쇼츠 시청자의 상당수가 음소거로 보고,
"틱타알릭", "등시선", "내인성 레트로바이러스" 같은 단어는 자동자막이 거의 못 맞힙니다.

## 3. 유튜브 쇼츠 vs 틱톡 — 같은 영상, 다른 운영

두 플랫폼은 **같은 영상을 올리되 운영을 다르게** 합니다.

| | 유튜브 쇼츠 | 틱톡 |
|---|---|---|
| 강점 | 검색·장기 노출, 주제 권위 축적 | 초기 확산 속도 |
| 수명 | 수개월~수년 (검색 유입) | 수일 (단, 재확산 있음) |
| 제목 | **검색어 중심** — "방사성 연대측정 신뢰도" | **후킹 중심** — "이 주장, 증거 있나요?" |
| 출처 | 고정 댓글 + 더보기란 | 고정 댓글 (설명란 짧음) |
| 워터마크 | 틱톡 워터마크 있는 영상 업로드 금지 | — |
| 용도 | **본진**. 자산 축적 | **유입구**. 여기서 발견되고 유튜브에서 소비 |

**중요**: 틱톡에서 내려받은(워터마크 박힌) 파일을 쇼츠에 올리지 마세요.
재업로드 콘텐츠로 분류되어 노출이 떨어집니다. **항상 원본 파일에서 각각 내보내기.**

## 4. 업로드 리듬

- **주 3회 (월·수·금)** — `claimctl.py calendar`가 이 슬롯으로 생성
- 시간대: 국내 기준 **19:00~21:00** 업로드 권장 (퇴근·하교 후 소비 피크)
- 두 플랫폼 **동시 업로드**. 시차를 두면 어느 쪽이 원본인지 알고리즘이 혼동
- **연속성이 빈도보다 중요합니다.** 주 3회를 못 지킬 것 같으면 처음부터 주 2회로 시작하세요.
  중간에 끊기는 게 처음부터 느린 것보다 훨씬 손해입니다.

## 5. 제목·해시태그

`claimctl.py meta EP0XX`가 두 플랫폼용을 각각 생성합니다.

**제목 원칙**
- 낚시 금지. 영상이 답하지 않는 질문을 제목에 걸면 완주율이 떨어지고, 그게 곧 노출 하락
- 주장을 **인용부호로** 묶어 제시: `"진화는 이론일 뿐"이라는 말의 함정`
- 조롱조 금지 — 비타깃이 방어하지 않고 끝까지 보게 만들어야 설득이 일어남

**해시태그**
- 4~6개. 주제 태그 2 + 분야 태그 2 + 광역 태그 1~2
- 틱톡 캡션은 **150자 이내** (초과분은 접힘)

## 6. 알고리즘에 대해 정직하게

추천 알고리즘의 작동 방식은 공개되어 있지 않고, 자주 바뀝니다.
확실히 말할 수 있는 건 플랫폼이 공식적으로 밝힌 것뿐입니다:

- 완주율·재시청이 강한 신호다 (양사 공식 언급)
- 초기 몇 시간의 반응이 이후 노출에 영향을 준다
- 댓글·공유·저장이 단순 좋아요보다 무겁게 취급된다

나머지 "알고리즘 공략법"은 대부분 추측입니다.
**우리가 통제할 수 있는 건 완주율뿐이고, 그건 대본 품질의 함수입니다.**
이 채널의 성장 전략은 사실상 "좋은 대본"이 전부입니다.

## 7. 정책 리스크

종교 관련 주제는 플랫폼 정책 경계에 가깝습니다. 방어선:

1. 영상 안에 **"이 채널은 종교를 비판하지 않습니다. 검증 가능한 주장만 다룹니다"**를
   고정 댓글에 매번 포함 (템플릿에 이미 포함됨)
2. 특정 종교 집단을 지칭하는 이미지·상징의 조롱적 사용 금지
3. 신고 누적 시 이의제기용으로 대본과 출처가 리포에 남아 있음 — **버전 관리가 곧 방어 증거**
4. 채널 정지 대비: 영상 원본과 대본은 항상 로컬+클라우드 이중 백업
