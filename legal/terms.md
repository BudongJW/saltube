## 3. What the tool does

It authenticates to TikTok using TikTok's OAuth flow, then sends video files to
the authenticated account's TikTok inbox (drafts) through the Content Posting
API using the `video.upload` scope. **It does not publish posts.** The account
holder completes and publishes each post manually inside the TikTok app.
