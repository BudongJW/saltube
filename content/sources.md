# 출처 마스터 목록

대본 front matter의 `sources:` 항목은 여기 있는 **ID**를 참조합니다.
`tools/claimctl.py validate`가 대조 검사합니다.

## 규칙

1. **1차 출처만.** 논문, 학술서, 정부·연구기관 데이터, 법원 판결문.
2. 블로그·위키백과·유튜브는 **배경 조사용**으로만. 여기 등재 불가.
3. 각 항목에 **DOI / ISBN / 기관 URL / 사건번호** 중 최소 하나.
4. 등재 전 **원문을 직접 확인**할 것. 초록만 읽고 등재 금지. → [편집 정책](../docs/03-editorial-policy.md) §2

> ⚠️ **아래 목록은 조사 착수용 초안입니다.** 각 항목은 대본에 인용하기 전에
> 원문 대조(2단계 검증)를 거쳐야 하며, 확인을 마친 항목만 `verified: yes`로 표시합니다.
> 미확인 항목을 인용한 대본은 `validate`에서 경고가 뜹니다.
